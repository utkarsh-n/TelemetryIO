# Instrument direction

The screen is a dark phosphor instrument. Liquid Glass belongs to navigation and controls, following Spectra's existing hierarchy. Content uses near-black green wells, faint graticules, thin luminous traces, monospaced readings and a serif opening statement. Motion is mint, environment/device amber, audio/output rose, location/touch ice and radio violet.

Gyre supplies relative-drag rotary mechanics, meaningful detents, double-tap reset and direct manipulation. Every dial also has a native slider and VoiceOver adjustment. Hardware values are not modified: patch mapping normalizes them into control signals, applies depth/inversion and time smoothing, then drives this app's visual or physical outputs.

The orbit field is an amplitude diagram. It doesn't claim physical antenna positions, RF wavefront measurements or BLE direction. Scope plots keep units and history; waterfall brightness represents each channel's own normalized range. Status badges and source explanations remain part of the instrument, so unavailable telemetry is a useful visible boundary.

Permissions are requested on deliberate source enablement. Sound and haptics start muted. Reduced Motion suppresses decorative movement; data remains readable. Accessibility text sizes stack dense rotary/control groups. The root model preserves shared capture and patch state across all tabs.
